-------------------------------------------------
     SG-1000(II), FG-1000, SC-3000, Othello 
 Multivision & Mark III/Korean Gam*boy ROM Loader
  for MSX with Musical Memory Mapper cartridge

              v.0.92 r2 by GDX
-------------------------------------------------

SG1000.COM allows SG-1000 games to work on MSX.
Musical Memory Mapper or Playsoniq cartridge allows to get a perfect sound.
You will not get sound without one of these two cartridges.


Using:

 SG1000.COM is a MSX-DOS1/2 command. 
 Input the command and file name of the ROM in following order.

  >SG1000 RomName.ext


Example:

  A>SG1000 DROL.SG

Notes:
- The player 2 is supported for most games.
- About MarkIII/Korean Gam*boy roms, only a few games that use a screen mode
  supported by the TMS9918 can work.
- The keyboard is not supported.
- This loader doesn't support 48KB ROM or bigger. (See Extra folder for 48KB Roms)
- Musical Memory Mapper is a cartridge made by Popolon (fr).
   http://www.msxvillage.fr/forum/topic.php?id=2423#m56345
   http://www.ebsoft.fr/shop/fr/home/35-musical-memory-mapper.html
- Playsoniq is a cartridge made by SuperSoniqs.
   http://supersoniqs.com/category/playsoniq/
